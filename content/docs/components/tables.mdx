Use a table for lookups, with a name in the first column and facts about it in the others.
They use the Markdown syntax.

| Project | On dark | On white |
| --- | --- | --- |
| Aiviarium | `#3FCF8E` | `#12875A` |
| Rookery | `#F2B33D` | `#9A6200` |
| Parrot | `#FF6369` | `#D1343B` |
| Crow | `#8F8FFA` | `#4A4AC8` |
| Hatchery | `#E879F9` | `#A21CAF` |

## MDX

```md
| Project | On dark | On white |
| --- | --- | --- |
| Aiviarium | `#3FCF8E` | `#12875A` |
| Hatchery | `#E879F9` | `#A21CAF` |
```

## Alignment

A colon in the separator row aligns a column.

| Left | Centre | Right |
| :--- | :---: | ---: |
| a | b | 1 |
| cc | dd | 22 |

Table cells have no background colour.
Write short cells, and move long text into the paragraphs around the table.
